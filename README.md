# Student Grade Calculator

## About
This project is a simple JavaScript program that calculates a student's grade based on marks.

## Features
- Stores student marks in a variable
- Adds bonus marks using the `+=` operator
- Determines grade using `if-else` statements
- Determines Pass/Fail status using a ternary operator
- Displays remarks using a `switch` statement
- Prints results to the console

## Technologies Used
- JavaScript

## Concepts Used
- Variables
- Assignment Operators
- Conditional Statements (`if-else`)
- Ternary Operator
- Switch Statement
- Console Output

## How to Run
1. Save the code in a file named `gradeCalculator.js`.
2. Open a terminal.
3. Navigate to the project folder.
4. Run:

```bash
node gradeCalculator.js
```

## Sample Output

```text
marks: 80
grade: B
result: Pass
remarks: Good
```
